Ottimizzazioni per 2 × Quadro P4000

Parametri vLLM calibrati per GPU Pascal con VRAM limitata

Parametro Valore Motivazione
tensor-parallel-size 2 Divide il modello FP8 (~9 GB) su entrambe le GPU (~4.5 GB cad.)
enforce-eager attivo Pascal non supporta CUDA graphs in modo stabile; previene crash
gpu-memory-utilization 0.92 Utilizza ~7.4 GB degli 8 GB disponibili per GPU
max-model-len 16384 Contesto sufficiente per traduzione; risparmia ~1 GB VRAM per GPU
max-num-seqs 128 Throughput bilanciato senza rischio OOM su 8 GB
kv-cache-dtype fp8 KV cache in FP8 allineata al modello; dimezza la memoria per cache
block-size 16 Blocchi piccoli riducono la frammentazione della VRAM
num-scheduler-steps 8 Pipeline scheduling per migliorare il throughput
count (deploy) 2 Docker riserva esplicitamente entrambe le GPU

API

Endpoint DeepL-style e compatibilità OpenAI

POST /translate — Traduzione singola

# Richiesta
curl -X POST http://localhost:8080/translate \
  -H "Content-Type: application/json" \
  -d '{
    "text": "The Canton of Ticino is the southernmost canton of Switzerland.",
    "source_lang": "English",
    "target_lang": "Italian",
    "context": "public administration"
  }'
# Risposta
{
  "translations": [
    { "text": "Il Canton Ticino è il cantone più meridionale della Svizzera.",
      "target_lang": "Italian" }
  ],
  "detected_source_lang": "English",
  "model": "apertus-translator",
  "usage": { "prompt_tokens": 87, "completion_tokens": 18, "total_tokens": 105 },
  "timings": { "total": 0.42 }
}

POST /translate/batch — Traduzione multipla

curl -X POST http://localhost:8080/translate/batch \
  -H "Content-Type: application/json" \
  -d '{"texts":["Hello","Goodbye"],"target_lang":"Italian"}'

API OpenAI-compatible

curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "apertus-translator",
    "messages": [
      {"role": "system", "content": "You are a professional translator."},
      {"role": "user", "content": "Translate to Italian: Good morning"}
    ]
  }'

GET /health — Stato del servizio

curl http://localhost:8080/health
# {"status":"ok","vllm":"up","model":"artificialy/Apertus-v1.5-8B-FP8-DYNAMIC"}

Avvio Rapido

Deploy completo in due comandi

# 1. (opzionale) Token HuggingFace per modelli gated
export HF_TOKEN=hf_xxx

# 2. Avvia lo stack
docker compose up -d

# 3. Monitora il download dei pesi (~9 GB)
docker compose logs -f vllm

# 4. Verifica lo stato
curl http://localhost:8080/health
